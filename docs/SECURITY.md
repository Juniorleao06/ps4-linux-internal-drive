Security and Safety Guidelines

Experimental Software Warning

PS4 Linux Internal Drive — Baikal Edition is an experimental community project.

The installation method has been tested on one PS4 Slim Baikal console. Other hardware revisions and firmware versions may behave differently.

Protect Your Data

- Back up important PS4 data before attempting installation or recovery.
- Never format the entire PS4 internal HDD as part of this procedure.
- Avoid using destructive commands without understanding their effects.
- Do not select "RESET" in the tested boot menu unless you deliberately intend to erase the Linux installation.
- Keep copies of your working kernel, initramfs and configuration files.

Download and Binary Safety

- Obtain boot files and Linux root filesystems from sources you trust.
- Verify file hashes when trusted reference hashes are available.
- Do not run unreviewed installation scripts as root.
- Do not redistribute third-party binaries without checking their licenses and provenance.

Passwords and Privacy

- Change default passwords after installation.
- Never publish passwords, private keys, authentication tokens or personal files.
- Review logs and configuration files before uploading them to GitHub.

Reporting Problems

Open a GitHub issue describing the console model, firmware version, kernel version and steps needed to reproduce the problem.

Do not include passwords, private keys or other sensitive information.
