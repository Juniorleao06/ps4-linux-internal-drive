Project Modification and Testing

Modified and tested by Juniorleao06

GitHub: https://github.com/Juniorleao06

This repository documents an experimental method of running Linux from an ext4 loopback image stored on the PlayStation 4 internal HDD.

The configuration was tested on a PS4 Slim Baikal console running firmware 13.52.
